Shaka Player: a session dropped after a failed license request is never closed

The page plays the Shaka demo asset Multi-DRM, multi-key, which has one key per representation and so opens several Widevine sessions. It waits for the license exchange, destroys the player, and reports whether each MediaKeySession was closed. Use Chrome or Edge.

With failing license requests, every failure while another session is still open removes that session from DrmEngine's list without closing it, and destroy() only closes the sessions on that list. Expected result: 0 sessions open after destroy().
